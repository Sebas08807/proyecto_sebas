Proyecto Git Práctica

Descripción
Este proyecto corresponde a una práctica académica enfocada en el uso de sistemas de control de versiones con Git. 
Se implementaron operaciones básicas y avanzadas como la creación de repositorios, 
commits, uso de ramas, fusión de cambios y sincronización con plataformas remotas como GitHub.

Tecnologías utilizadas
- Git (control de versiones)
- GitHub (repositorio remoto)
- Editor de código (VS Code / Notepad / etc.)

Estructura del proyecto
- "Prueba #1.txt" → Archivo de prueba para commits
- ".gitignore" → Archivo para ignorar elementos innecesarios
- "README.md" → Documentación del proyecto

Cómo clonar el proyecto
git clone https://github.com/Sebas08807/proyecto_sebas.git

Luego ingresar a la carpeta:
cd Proyecto_sebas

Cómo ejecutar el proyecto
Este proyecto es de práctica, por lo tanto no requiere ejecución específica.
Solo se deben visualizar o editar los archivos dentro del repositorio.

Flujo de trabajo con Git

Durante la práctica se realizaron las siguientes acciones:
- Inicialización del repositorio ("git init")
- Seguimiento de archivos ("git add")
- Registro de cambios ("git commit")
- Creación de ramas ("git branch")
- Cambio entre ramas ("git checkout")
- Fusión de ramas ("git merge")
- Sincronización con GitHub ("git push", "git pull")

Contribuciones.
Para contribuir al proyecto:

1. Realizar un fork del repositorio

2. Crear una nueva rama:

git checkout -b nueva-rama

3. Realizar cambios y hacer commit:

git commit -m "Descripción del cambio"

4. Subir cambios:

git push origin nueva-rama

5. Crear un Pull Request en GitHub

Problemas comunes y soluciones.
- Error al hacer push → usar "git pull --rebase"
- Conflictos de merge → editar el archivo y confirmar cambios
- Problemas de autenticación → iniciar sesión en navegador
